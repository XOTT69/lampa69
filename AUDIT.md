# Причини збоїв та зміни XOTT Online 0.10.0

Перевірено 15 жовтня 2026 року. Вхідний плагін: ревізія `42316e4245cb799f4ebe1a20a64c8a716b631a34`. Поточний main на початку роботи: `10dac78459da0c95a2701240e72aadbc506ca766`.

## Що встановлено

- XOTT 0.9 делегує HDRezka, Filmix, CDNVideoHub, Kodik та AniLibria окремому Online MOD. Ці реалізації не беруть джерела із сервера Lumio.
- У використаній ревізії Online MOD Filmix починає з `max_qualitie: 480`. Підвищення залежить від відповіді `user_profile`; змінювати число без реального доступного потоку некоректно.
- Lumio 1.26.0 звертається до `https://beta.mitsu.tv/api`, отримує список `/lite/events`, ідентифікатори `/externalids` та сторінки `/lite/{provider}`. Його відкритий JS не містить самого серверного бекенда.
- Сервер дозволив CORS для домену KADR UA. Список провайдерів залежить від відповіді сервера та не гарантує наявність відео.
- Для відкритого Big Buck Bunny Filmix повертав карту 480p. VeoVeo повертав адаптивний HLS із варіантами до 1920×1080. Українські провайдери можуть вимагати RCH або не мати цього фільму.
- Деяким провайдерам потрібні IMDb / TMDB ID: назви недостатньо. Новий клієнт запитує зовнішні ID через `/externalids`, якщо їх немає у картці.
- Важливо зберігати підписаний master HLS URL: він може перенаправляти на інший CDN і містити окремі аудіогрупи. Відкриття відносного дочірнього плейлиста на початковому домені призводило до HTTP 401. Новий клієнт зберігає master URL; рівні якості читаються з маніфесту.

## Реалізація

`src/source-client.js` — власний клієнт протоколу, спільний із KADR UA. Він читає JSON та інертний HTML `data-json`, не вставляє отриманий HTML у документ, обмежує розмір відповідей і не виконує скрипти. Резолвери та папки обмежено налаштованим API. Підтримано таймаути, пояснення RCH, якість, озвучки та вкладені сезони/серії.

`src/lampa-ui.js` — новий інтерфейс джерел у Lampa. `src/legacy-online.js` зберігає попередній власний плагін як резервний пункт, без дублювання кнопки на картці. `plugin.js` — зібраний файл для встановлення.

Код, логотипи та телеметрія Lumio не копіювалися. Не додано чужих облікових даних або обходу тарифів Filmix.

## Перевірки та межі

- Node-тести протоколу, мап якості, підписаного HLS master URL та інтеграції з імітованим API Lampa.
- Реальні HTTP/CORS-запити до джерел; у Chrome KADR UA відтворив VeoVeo з videoWidth=1920 і videoHeight=1080. Перевірено вибір HLS-рівня, аудіодоріжки та збереження прогресу після перезавантаження.
- Апаратні Android TV / webOS / Tizen у цій сесії недоступні; тест API Lampa не є перевіркою конкретного телевізора.
- RCH не реалізовано новим клієнтом. Для відповідних провайдерів доступні зрозуміла помилка, інший сервер або резервний Online MOD. Доступність зовнішнього API може змінюватися.

Джерела аналізу: https://github.com/XOTT69/lampa69, вказана pinned-версія plugin.js, https://beta.mitsu.tv/plugins/lumio.js та pinned Online MOD, указаний у вихідному плагіні.
