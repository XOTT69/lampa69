# XOTT Online v0.9 — без VPS і ручних налаштувань HDRezka

### Встановлення у Lampa MX

```
https://cdn.jsdelivr.net/gh/XOTT69/lampa69@42316e4245cb799f4ebe1a20a64c8a716b631a34/plugin.js
```

Видаліть попередню XOTT Online з **Налаштування → Плагіни**, додайте URL вище, повністю перезапустіть Lampa MX, відкрийте картку → **Онлайн**.

### HDRezka — один пункт у меню

XOTT сам перевіряє пошук фільму через кілька маршрутів до HDRezka (через два сервери сторонніх проксі й пряме підключення) та використовує перший маршрут, який повернув схожий на справжній результат пошуку. Вибір кешується на 2 хвилини, після чого перевірка повторюється. Доступ до відео, авторизація чи якість **не гарантуються** результатом мережевої перевірки. У разі неможливості доступу XOTT показує зрозуміле повідомлення, а не стверджує, що в користувача відсутній інтернет.

Технічно XOTT використовує сторонній [Онлайн МОД](https://github.com/nb557/plugins/blob/main/online_mod.js); у ньому HDRezka має код балансера `rezka2`. XOTT встановлює параметри `online_mod_proxy_rezka2`, `online_mod_proxy_rezka2_mirror`, `online_mod_proxy_other`, `online_mod_proxy_other_url`. Значення загального проксі перед переглядом в інших джерелах відновлюються.

Автоматична перевірка використовує запит пошуку *без авторизаційних токенів або паролів*. Зверніть увагу, що обраний третій проксі та зовнішній JS можуть отримувати метадані запитів; на першому запуску потрібне підтвердження завантаження стороннього модуля. Якщо провайдер чи дзеркала/проксі недоступні, гарантувати перегляд без власного сервера неможливо.

### Filmix — власний акаунт, 720p+

**Не потрібен власний ключ API XOTT.** Для HD-якості Filmix використовує права власного Filmix-акаунта. У модулі стандартна межа **480p** без підтвердженої авторизації. Після перевірки `user_profile` Filmix він може підвищити межу до **720p**, із доступом PRO — 1080p, PRO PLUS — 2160p (якщо відповідні відеопотоки справді доступні).

Для підключення:
1. XOTT → Онлайн → **«Filmix · налаштувати якість (720p+)»**.
2. У налаштуваннях Filmix вибрати **«Додати пристрій на Filmix»**.
3. Модуль показує одноразовий код; у **своєму браузері та своєму Filmix-акаунті** відкрити сторінку, яку показав модуль (`filmixHost/consoles`), і ввести код **там, не в чаті**.
4. Після підтвердження онлайн-модуль зберігає токен **локально в Lampa.Storage** і визначає доступні якості. Платний статус і наявність 720/1080/2160 залежать від Filmix.

Ні пароль, ні одноразовий код, ні токен **не надсилати у публічний GitHub і не передавати у чат**. У XOTT немає проксі для авторизації Filmix, а сторонній онлайн-модуль може використовувати свої мережеві проксі.
