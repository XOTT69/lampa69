# XOTT Online v0.6 — без сервера для Lampa MX

**Один JS-плагін для кнопки «Онлайн» без власного VPS.** Встановлення:
```
https://cdn.jsdelivr.net/gh/XOTT69/lampa69@13386e69/plugin.js
```

1. Lampa MX → Налаштування → Плагіни → видалити попередню версію XOTT Online.
2. Додати адресу вище й **повністю перезапустити Lampa MX**.
3. Відкрити картку фільму → **Онлайн**.
4. Вибрати Filmix, HDRezka/інші або відкриті архіви.
5. При першому виборі Filmix/Онлайн МОД підтвердити підключення стороннього JS. Після завантаження XOTT відкриває онлайн-екран **із пошуком саме поточного фільму**; озвучку та якість обирають в інтерфейсі джерела.

## Джерела

| У XOTT | Що запускається | Може потребувати |
| --- | --- | --- |
| Filmix | [Filmix FX](https://github.com/lampaplugins/store/blob/main/fx.js), `online_fxapi` | акаунт, токен або активацію пристрою; доступні якості залежать від сервісу |
| HDRezka та інші | [Онлайн МОД](https://github.com/nb557/plugins/blob/main/online_mod.js), `online_mod` | вхід в акаунт, налаштування джерел, сторонні проксі/API |
| Internet Archive | Вбудований пошук архіву | наявність фільму в архіві |
| Wikimedia Commons | Вбудований пошук відкритих відео | наявність файлу |

HDRezka відкривається **через список джерел Онлайн МОД**, а не як окремий прямий парсер XOTT. Після відкриття Онлайн МОД треба вибрати HDRezka у його меню (якщо джерело доступне). **Інтеграції не гарантують жодного конкретного фільму чи озвучки**.

## Безпека і вартість

- Для XOTT **не потрібні VPS, Lampac, Docker або оплата хостингу**. Сам JS розміщений у GitHub/CDN безкоштовно.
- Онлайн-джерела можуть звертатися до сторонніх серверів/проксі, а деякі мають платні умови чи обмеження; це **не означає**, що всі новинки безкоштовні.
- Filmix FX та Онлайн МОД — **сторонні скрипти**. Вони отримують доступ до середовища Lampa; запускаються **лише після підтвердження** в XOTT, URL джерел наведені вище. Не передавайте XOTT свої паролі. Якщо потрібна авторизація, вводьте її лише у вікнах відповідних сервісів, розуміючи їхню політику.
- Оновлення сторонніх скриптів розробниками може змінити поведінку. Українська доріжка або 1080p/4K з'являться тільки якщо джерело їх надає.
- `deploy/` — **старі необов'язкові файли для власного VPS**, до поточної безсерверної версії не належать.

## Перевірка

Встановіть XOTT, відкрийте картку фільму, натисніть **Онлайн → Filmix**. Якщо воно відкрило екран Filmix, перевірте пошук і вибір озвучки/якості. Після цього спробуйте **Онлайн → HDRezka та інші**. Якщо отримали помилку, надішліть скриншот та назву фільму — ми перевіримо конкретну інтеграцію.

Перевірка JS на синтаксис виконана. Тестування мережевих викликів та відтворення на реальному Lampa MX **ще не проведено**.
