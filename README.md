# XOTT TV 2.1 — українська Lampa з власними адаптерами джерел

Самостійна збірка Lampa 3.4.1 для браузера й телевізорів, зокрема Hisense/VIDAA через MSX. Репозиторій містить оболонку, власний плагін, сервер джерел та Telegram-акаунти. Старий XOTT Online видалений.

## Джерела

У картці фільму натисніть **«Дивитися · XOTT» → Filmix**. Пошук автоматично використовує оригінальну назву та рік. Однозначний збіг відкривається автоматично; інакше пропонується список результатів. Далі доступний вибір озвучки, якості, сезону й серії.

- **Filmix:** незалежний гостьовий адаптер, до 480p. Перевірено живий пошук «Shrek», отримання 5 потоків і HTTP 206 при запиті частини відео. Це перевірка одного прикладу, а не обіцянка доступності кожного фільму.
- **HDRezka:** додано окремий експериментальний адаптер гостьових фільмів. Під час живої перевірки джерело відповідало HTTP 405. Воно не позначається гарантовано робочим. Серіали в цьому адаптері поки не підтримуються.
- **Власний каталог:** з'являється тільки після налаштування HTTPS JSON-каталогу. Формат — `catalog.example.json`.

Результати, позначені джерелом як заблоковані, та посилання з явними рекламними прапорцями не віддаються для перегляду. Доступу до захищеного контенту або PRO-якості без власної авторизації немає. У поточному адаптері не передаються паролі чи токени Filmix. HTTP API Filmix викликає сервер; браузер звертається до нашого API через HTTPS.

## Запуск

Після публікації GitHub Pages вебверсія: `https://xott69.github.io/lampa69/app/`.

На телевізорі:

1. Встановити **Media Station X** із магазину застосунків, якщо він доступний для моделі/регіону.
2. **Settings → Start Parameter → Setup**.
3. Ввести **`xott69.github.io/lampa69`** без протоколу. Підкаталог `/lampa69` обов'язковий.

Для першого увімкнення Pages: **Settings → Pages → Source → GitHub Actions**, потім повторити workflow збірки. До цього адреса повертає 404. Якщо MSX не приймає підкаталог, потрібен запуск через MSX Launcher або власний домен у корені.

Для джерел потрібен запущений API з `server/`. У GitHub **Variables** вказати `XOTT_PROVIDER_API_URL=https://ваш-worker/api/providers`, потім перебудувати сайт. Можна також задати адресу в **Налаштування → XOTT Sources → Сервер джерел**. Сам GitHub Pages серверний API не виконує.

## Telegram-акаунт

**Налаштування → XOTT TV → Увійти через Telegram**: код і QR на екрані, підтвердження кнопкою в боті. Після входу синхронізуються закладки, історія та прогрес. Ключі сторонніх джерел не синхронізуються. Telegram-вхід потребує власного бота, D1 і секретів Worker; без них він неактивний. Деталі: [server/README.md](server/README.md).

## Без реклами в оболонці

Зі збірки виключено рекламний менеджер, прероли/VAST/IMA й надсилання метрик. Власний плагін працює тільки з прямими MP4/HLS/WebM, не відкриває iframe чи сторонні сторінки. Реклама, вже вшита в чужий відеофайл, автоматично не вирізається; довільні сторонні плагіни можуть мати власну поведінку.

## Сумісність і відновлення

Збережено API `window.Lampa`, плагіни за URL, плеєр, пошук, історію, закладки та керування пультом. Українська мова встановлюється за замовчуванням і не перезаписує вибір користувача. Для TV використовується легший фон і вимкнені складні анімації.

**Налаштування → XOTT TV → Діагностика телевізора** показує версію, браузер, MP4/HLS та сховище. `app/?safe=1` запускає оболонку без сторонніх і вбудованого джерельного плагінів, зберігаючи список і параметри.

Перевірка на реальному Hisense 32A4N ще потрібна: запуск MSX, стрілки/OK/Назад, пошук, пауза, перемотування та вихід із плеєра. Підтримка кожного кодека чи плагіна не гарантується.

## Збирання й тести

Потрібні Git та Node.js 22+:

```sh
git clone https://github.com/XOTT69/lampa69.git
cd lampa69
git clone https://github.com/yumata/lampa-source.git .upstream
git -C .upstream checkout 616c80224518a7c7e04e2789d5811881b93bf611
cp upstream-lock.json .upstream/package-lock.json
npm ci --prefix .upstream --ignore-scripts --no-audit --no-fund
npm run build
npm test
python3 -m http.server 8765 --directory dist
```

Змінні: `LAMPA_SOURCE` — локальний каталог джерел, `SITE_URL` — абсолютна адреса публікації, `XOTT_API_URL` — сервер акаунтів, `XOTT_PROVIDER_API_URL` — API джерел, `XOTT_CATALOG_URL` — необов'язковий каталог.

16 автоматичних перевірок охоплюють вхід, приватність, конфлікти синхронізації, обмеження джерел, блокування реклами й небезпечних URL, гостьову якість та склад збірки. Живі запити до джерел не входять до CI, щоб збій стороннього сайту не ламав збірку.
