# XOTT Online — Lampa MX

Плагін додає кнопку **Онлайн** безпосередньо в картку фільму.

## Встановлення

Налаштування Lampa MX → Плагіни/Розширення → Додати плагін:

https://cdn.jsdelivr.net/gh/XOTT69/lampa69@main/plugin.js

Після встановлення перезапустіть Lampa MX.

## Поточна версія (прототип 0.2)

1. Відкрийте картку фільму.
2. Натисніть **Онлайн**.
3. Виберіть джерело Internet Archive.
4. Виберіть результат пошуку, звукову доріжку (у поточному джерелі лише оригінальна) та відеофайл/якість.
5. Запустіть вбудований плеєр.

**Обмеження:** тільки відео, доступні через Internet Archive; наявність конкретного сучасного фільму, української озвучки та певної якості не гарантована. Доступність API, CORS, підтримка форматів і реакція меню можуть відрізнятися між збірками Lampa MX. На реальному пристрої плагін ще не протестований.

Проєкт не включає обходу DRM або парсингу нелегальних трансляцій.
