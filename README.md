# XOTT Online v0.7 — онлайн-перегляд у Lampa MX без VPS

**Картка фільму/серіалу → Онлайн → HDRezka / Filmix / CDNVideoHub / Kodik / AniLibria → варіанти озвучки, сезонів, серій і якості у вибраному джерелі.**

Плагін сам зберігає обраний балансер (`online_mod_balanser`) і відкриває **відразу відповідне джерело**, без додаткового меню «Онлайн МОД». Джерела Filmix/HDRezka/інші реалізовані інтеграцією з [Онлайн МОД](https://github.com/nb557/plugins/blob/main/online_mod.js) (сторонній клієнтський JS, без нашого VPS). Він керує пошуком відео, озвучками, сезонами, серіями, доступними форматами та запуском у плеєрі. Це **не** незалежні власні парсери XOTT: якщо зовнішній модуль або API джерела перестануть працювати, XOTT не зможе сам отримати потоки.

## Встановлення

1. Lampa MX → Налаштування → Плагіни: видалити старі XOTT Online, якщо вони встановлені.
2. Додати адресу:
   ```
   https://cdn.jsdelivr.net/gh/XOTT69/lampa69@b310d39f73bf92595c959062425e7484de493eda/plugin.js
   ```
3. Повністю перезапустити Lampa MX.
4. Відкрити картку фільму → **Онлайн** → **HDRezka** або **Filmix**.
5. На першому запуску підтвердити завантаження зовнішнього JS-модуля. Після цього він запускається тільки один раз за сесію. XOTT приховує його дубльовану кнопку, залишаючи власне меню.
6. У результатах джерела обирати **доступну озвучку**, сезон, серію та якість. Конкретний порядок екранів визначає зовнішній онлайн-модуль.

## Умови та обмеження

- Для нашого плагіна **немає потреби орендувати VPS**: GitHub/CDN віддає JS, а провайдерські запити виконуються через механізми зовнішнього онлайн-модуля.
- Сторонній модуль може використовувати віддалені сервери, проксі, вимагати обліковий запис, обмежувати якість або блокувати окремі фільми залежно від країни.
- **Ні безкоштовність усіх новинок, ні наявність української озвучки/4K не гарантовані.** XOTT не обходить платну авторизацію, обмеження DRM чи захист відеопотоків.
- Зовнішній код Онлайн МОД завантажується за **закріпленою ревізією** `nb557/plugins@851bcc9bc064ac06dc2b0e7ff6631baba61be511` через jsDelivr. За потреби оновлення ревізію змінюємо після перевірки.
- Плагін Lumio, наданий як приклад, використовує свій сервер `beta.mitsu.tv/api`; він не є серверонезалежним парсером. Cardify/NoTrailer стосуються інтерфейсу і не є потоковими джерелами. 
- `deploy/` — **необов'язкові старі файли** для власного сервера Lampac; поточна безсерверна версія їх не використовує.

## Перевірка

JS проходить синтаксичну перевірку. На макеті Lampa перевірено переходи між `rezka2` / `filmix` / `kodik` і відсутність повторного завантаження JS. Проте **реальні відеопотоки, озвучки, сезони, серії та якість треба перевірити на пристрої**; стан зовнішніх API може змінюватися.

Для діагностики надішліть назву фільму, обране джерело і скриншот помилки.
