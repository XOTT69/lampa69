# XOTT Online v0.5 — Lampa MX

Plugin: https://cdn.jsdelivr.net/gh/XOTT69/lampa69@9ad30c9a/plugin.js

Після відкриття картки фільму → **Онлайн**:
- **Filmix**: лише після окремого підтвердження користувача підвантажує сторонній [fx.js](https://github.com/lampaplugins/store/blob/main/fx.js). Розширення має власний UI і може вимагати токен/налаштування. Успіх пошуку чи перегляду не гарантований.
- **HDRezka та інші через Lampac**: введіть URL вашого вже запущеного сервера Lampac, далі під'єднайте його модуль `/on.js`. Для HDRezka потрібна ввімкнена інтеграція на бекенді. Проєкт: https://github.com/lampame/lampac-ng
- **Internet Archive**, **Wikimedia Commons**: відкриті джерела, інтегровані безпосередньо в XOTT.

Поточне обмеження: Filmix та Lampac запускаються як окремі модулі, не як повністю уніфікований список доріжок у XOTT. Наявність сучасного фільму, конкретної озвучки, 1080p/4K, обмеження сервісу або потреба у підписці залежать від провайдера. Не обіцяється універсальний безкоштовний доступ. Не вставляйте токени в публічний репозиторій.

JavaScript пройшов перевірку синтаксису; тесту на реальному телевізорі ще не було.
