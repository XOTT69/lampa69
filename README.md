# XOTT Online 0.10.0 для Lampa

Адреса встановлення:

https://kadr-ua.mikolenkoanton7.chatgpt.site/lampa/plugin.js

1. Налаштування Lampa → Плагіни → видаліть попередній XOTT Online.
2. Додайте адресу вище та повністю перезапустіть Lampa.
3. Відкрийте картку фільму → Онлайн → оберіть джерело.
4. Оберіть доріжку / сезон / серію й одну з якостей, реально повернутих сервером.

За замовчуванням використано сторонній API `https://beta.mitsu.tv/api`, який також використовує Lumio. У меню джерел є «Налаштувати сервер джерел» для власного сумісного Lampac API. Код Lumio та його оформлення не копіювалися.

Filmix може повертати лише 480p; плагін не підміняє права акаунта та не додає несправжні 1080p-пункти. Для інших якостей оберіть інше джерело. Резервний пункт «Старі джерела / Filmix · мій акаунт» зберігає попередній Online MOD і власні налаштування Filmix.

Деяким серверам потрібен клієнт RCH або нативні мережеві можливості. Якщо джерело просить RCH, новий адаптер показує причину; для нього можна спробувати резервний Online MOD або сумісний сервер. Список провайдерів не гарантує наявності відео. Доступність залежить від сервера, регіону та мережі.

Підключений сервер отримує запити з назвами фільмів та технічним ID сесії. Власних акаунтів, токенів або телеметрії Lumio в цьому плагіні немає.
