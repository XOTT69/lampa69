# XOTT TV — власна Lampa для телевізорів і браузера

Окремий вебзастосунок на основі Lampa 3.4.1. Репозиторій `lampa69` тепер містить застосунок, а попередній XOTT Online видалено. Джерела перегляду автоматично не встановлюються.

## Запуск на Hisense 32A4N / VIDAA через Media Station X

Після успішної публікації GitHub Pages:

1. Встановити **Media Station X** із магазину телевізора, якщо він доступний для вашої моделі та регіону.
2. Відкрити **Settings → Start Parameter → Setup**.
3. Ввести **`xott69.github.io/lampa69`** (без `https://`, шлях `/lampa69` обов'язковий).
4. Підтвердити й відкрити XOTT TV.

Вебверсія: **https://xott69.github.io/lampa69/app/**

Якщо версія MSX не приймає стартову адресу з підкаталогом, використати [MSX Launcher](https://launcher.msx.benzac.de/) для відкриття вебверсії або розмістити `dist/` у корені власного домену та перебудувати із `SITE_URL=https://ваш-домен/`.

### Перше увімкнення GitHub Pages

У **Settings → Pages → Build and deployment → Source** вибрати **GitHub Actions**. Потім запустити **Actions → Build and publish XOTT TV → Run workflow**. До налаштування Pages адреса може повертати 404; наявність коду в GitHub сама по собі не означає, що застосунок опублікований.

## Можливості

- Збережено публічний API `window.Lampa`, завантаження JS-плагінів за URL, плеєр, каталог, пошук, історію, закладки, керування пультом.
- Український інтерфейс і мова метаданих за замовчуванням. Вибір користувача зберігається.
- Профіль для VIDAA/Hisense та інших TV-браузерів: навігація пультом, вимкнені складні анімації, легший фон, стандартний HTML5/HLS-плеєр. Існуючі параметри не перезаписуються.
- **Налаштування → XOTT TV → Діагностика телевізора**: версія, User Agent, підтримка MP4/HLS, стан сховища.
- Безпечний режим: **https://xott69.github.io/lampa69/app/?safe=1**. На цей запуск сторонні плагіни вимкнені; список і налаштування не видаляються.
- Вбудований CUB-акаунт і сокетна синхронізація вимкнені: історія та параметри зберігаються локально. Telegram-акаунт і синхронізація реалізовані власним сервером; для їх активації потрібне розгортання `server/`.

## Звичайні й власні плагіни

У **Налаштування → Розширення / Плагіни** додати HTTPS-адресу JS-плагіна та перезапустити. Джерела, що потребують акаунта, API чи сервера, налаштовуються окремо. Жодні токени не потрібно комітити в GitHub.

Власні плагіни використовують той самий API Lampa. Документація: https://github.com/yumata/lampa-source/tree/main/docs

Збереження API не гарантує роботу кожного стороннього плагіна. Обмеження джерела, CORS, HTTP/HTTPS, версії API, DRM, кодеків і прошивки телевізора залишаються. MSX відкриває застосунок; відтворення виконує плеєр Lampa в середовищі телевізора. APK для запуску через MSX не потрібен.

## Збирання

Потрібні Git, Node.js 22 і npm:

```sh
git clone https://github.com/XOTT69/lampa69.git
cd lampa69
git clone https://github.com/yumata/lampa-source.git .upstream
git -C .upstream checkout 616c80224518a7c7e04e2789d5811881b93bf611
cp upstream-lock.json .upstream/package-lock.json
npm ci --prefix .upstream --ignore-scripts --no-audit --no-fund
npm run build
npm test
python3 -m http.server 8765 --directory dist
```

Відкрити http://localhost:8765/app/. Змінна `LAMPA_SOURCE` дозволяє вибрати інший локальний каталог джерел; ревізія перевіряється. `SITE_URL` — абсолютна адреса публікації зі шляхом проєкту. Збірка не використовує live-CDN для ядра: всі ресурси ядра публікуються разом із застосунком.

GitHub Actions збирає `dist/`, перевіряє його, зберігає артефакт `xott-tv-static` і публікує через GitHub Pages. При зміні upstream потрібно оновити SHA в скрипті та workflow, lock-файл і повторити перевірки.

## Перевірка на телевізорі

Реальна перевірка на Hisense 32A4N ще потрібна. Перевірити запуск у MSX, стрілки/OK/Назад, пошук українською, встановлення плагіна, запуск дозволеного MP4/HLS-потоку, паузу, перемотування, повернення з плеєра і повторний запуск. Залежно від прошивки можуть знадобитися налаштування HLS або конкретного джерела. Сумісність з усіма телевізорами не заявляється.

## Вихідний код і ліцензія

Lampa: https://github.com/yumata/lampa-source, ревізія `616c80224518a7c7e04e2789d5811881b93bf611`, GPL-2.0 (див. `LICENSE`). Зміни XOTT TV поширюються на тих самих умовах. Збережено ліцензії сторонніх ресурсів upstream.

Зміни: окремий завантажувач/інтерфейс, локальний модуль налаштувань, початкові параметри, MSX-старт та доповнення визначення TV-профілю в `Platform.tv()` через `window.XOTT_TV`. Зміна ядра застосовується під час збирання у `scripts/build.cjs`; вихідний upstream не редагується.

`dist/source/lampa-source.tar.gz` містить точний вихідний upstream, `dist/source/package-lock.json` — залежності збірки. Наші файли й інструкції — у цьому репозиторії. `dist/build.json` містить версію, ревізію та контрольну суму застосунку.

Каталог і постери надходять від зовнішніх API. Відео не включено до застосунку. Попередній каталог `deploy/` містить застарілий окремий серверний варіант XOTT Online і не використовується цією збіркою.

## Версія 2: акаунт і власний плагін

Додані `server/` (Workers + D1), `app/account.js` та `plugins/sources.js`. Налаштування інфраструктури: [server/README.md](server/README.md).

Вхід: **Налаштування → XOTT TV → Увійти через Telegram**. На екрані з'являються код і QR, у боті потрібно підтвердити вхід. Синхронізуються закладки/історія та прогрес. Секрети акаунтів сторонніх джерел не передаються серверу.

Власний плагін вбудовано у звичайний запуск; у безпечному режимі його вимкнено. Окремий URL після публікації: `https://xott69.github.io/lampa69/plugins/sources.js`. Він підтримує власний каталог із вибором якості/озвучки/серій та публічний пошук відео в Internet Archive і Wikimedia Commons. Wikimedia може містити уривки; архівні результати потрібно звіряти за назвою й роком. Без джерела фільм із каталогу TMDB не стає доступним для перегляду.

Рекламний менеджер, прероли/VAST/IMA та надсилання метрик вилучені із графа збірки ядра. Наша оболонка й плагін не використовують рекламні SDK, iframe-плеєри або спливаючі сторінки. Код сторонніх плагінів і реклама, вшита у чуже відео, не можуть бути гарантовано контрольовані нашою оболонкою.

### Статус зовнішніх інтеграцій

Filmix, HDRezka та інші закриті джерела в цей власний плагін **не інтегровані**. Для них потрібні окремі перевірені адаптери, доступ до джерела та, де вимагається, власна авторизація. Плагін не отримує автоматично доступ до всіх фільмів із TMDB.

Без Cloudflare-деплою й секретів бота Telegram-акаунт не активний. Після додавання GitHub Variables `XOTT_API_URL` і, за потреби, `XOTT_CATALOG_URL` потрібно перебудувати сайт. Відео не передається через Worker: пристрій відкриває прямі потоки, щоб не витрачати серверний трафік на відео.
