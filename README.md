# XOTT Online v0.8 — Lampa MX

Власний VPS не потрібний. XOTT показує окремі джерела в меню картки. Після вибору джерела його сторонній онлайн-компонент шукає відео та показує доступні озвучки, сезони, серії й якість.

## Встановити v0.8

1. Видалити стару версію XOTT Online у Lampa MX → Налаштування → Плагіни.
2. Додати адресу:
   ```
   https://cdn.jsdelivr.net/gh/XOTT69/lampa69@32855c3bb531ecbe4512156cf91fbd147e744f3f/plugin.js
   ```
3. Повністю перезапустити Lampa MX.
4. Відкрити фільм → Онлайн → HDRezka / Filmix.

## HDRezka: мережеві помилки

У джерелах XOTT тепер три режими, які **використовують той самий балансер HDRezka в Онлайн МОД**, але по-різному налаштовують маршрут:
- **HDRezka · через проксі** — для вебзбірок Lampa; ввімкнено `online_mod_proxy_rezka2=true` і `online_mod_proxy_rezka2_mirror=true`. Онлайн МОД використовує своє дзеркало з налаштувань (за замовчуванням `https://kvk.zone`) через сторонній проксі.
- **HDRezka · напряму** — `online_mod_proxy_rezka2=false`; дозволяє спробувати прямі запити до дзеркала.
- **HDRezka · альтернативний сервер** — `online_mod_proxy_rezka2=true` і `online_mod_proxy_rezka2_mirror=false`, тобто інший домен `https://rezka.ag` через проксі.

**Як тестувати:** спочатку «через проксі», якщо «немає підключення до мережі» — «напряму», далі «альтернативний сервер». Це способи діагностики, а не гарантія доступу: якщо дзеркало або проксі заблоковані, жоден із режимів може не працювати. Використовується **сторонній проксі**, якому можуть бути видимі адреси запитів і службові дані; не вводьте паролі/авторизаційні cookies через невідомі проксі.

## Filmix: 480p / 720p / 1080p

- Онлайн МОД за замовчуванням обмежує Filmix до **480p**.
- При наявності токена пристрою він звертається до `user_profile` Filmix та, якщо профіль підтверджений, може встановити до **720p**, або **1080p/2160p** для тарифів із відповідними правами. Сервіс може вводити власні обмеження, тож навіть після входу конкретний файл може залишитись 480p.
- Новий пункт **«Filmix · налаштувати якість (720p+)»** відкриває Налаштування → Онлайн МОД → Filmix. Тут можна штатним способом прив'язати пристрій до свого акаунта, перевірити статус та тариф. Облікові дані або токен XOTT не запитує і не передає нам.
- XOTT **не підмінює 480p на 720p і не обходить права доступу**: у списку показується фактичний формат від джерела.

## Інші джерела

CDNVideoHub, Kodik, AniLibria (також через Онлайн МОД); вбудовані Internet Archive і Wikimedia Commons.

## Важливо

- Filmix, HDRezka й інші є сторонніми інтеграціями, а не власними серверами XOTT. Якість, доступність, озвучка та відеопотік залежать від провайдерів, мережі, прав доступу та конкретного фільму.
- Зовнішній [Онлайн МОД](https://github.com/nb557/plugins/blob/main/online_mod.js) використовується із закріпленою ревізією `851bcc9bc064ac06dc2b0e7ff6631baba61be511`; після першого вибору користувач підтверджує виконання його JS-коду.
- Синтаксис і налаштування маршрутів перевірено тестами з імітацією Lampa. **Роботу HDRezka і 720p на реальному пристрої поки не підтверджено**.
- Каталог `deploy/` лишився для необов'язкового VPS і не використовується у v0.8.
